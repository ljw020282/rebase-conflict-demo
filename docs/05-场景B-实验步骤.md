# 05 — 场景B：实验步骤（`--force` 抹掉他人提交）

对应脚本：[`scripts/04-scenario-B-lost-commits.py`](../scripts/04-scenario-B-lost-commits.py)

作用：Alice 在**未 fetch** 的过期 `feature` 上 rebase 后 `--force`，对比 `--force-with-lease` 的拦截，看 Bob 已推送的 CRITICAL 从远程「消失」。

与场景 A 独立，使用目录 `workspaces-lost/`。

在仓库**根目录**操作。

---

## 方式一：一键

关掉 `workspaces-lost/` 下已打开的标签，然后：

```bash
python scripts/04-scenario-B-lost-commits.py
```

脚本会打印 lease 拒绝、`--force` 成功、以及 `branch --contains` 为空。跳到 [完成后应有 / 验证](#完成后应有--验证) 自行复查即可。

---

## 方式二：手搓（与脚本等价）

### 1. 搭环境

```bash
rm -rf workspaces-lost
# Windows PowerShell:
# Remove-Item -Recurse -Force workspaces-lost -ErrorAction SilentlyContinue
mkdir workspaces-lost

git init --bare -b main workspaces-lost/origin.git

git clone workspaces-lost/origin.git workspaces-lost/alice
git -C workspaces-lost/alice config user.name "Alice"
git -C workspaces-lost/alice config user.email "alice@example.com"

git clone workspaces-lost/origin.git workspaces-lost/bob
git -C workspaces-lost/bob config user.name "Bob"
git -C workspaces-lost/bob config user.email "bob@example.com"
```

---

### 2. Alice：init + A1，推送 main / feature

```bash
cd workspaces-lost/alice
git switch -c main
```

**文件** `workspaces-lost/alice/note.txt`：

```text
base
```

```bash
git add .
git commit -m "init"
git switch -c feature
```

**文件** `workspaces-lost/alice/note.txt`（覆盖）：

```text
alice-1
```

```bash
git add .
git commit -m "feat: Alice work A1"
git push -u origin main
git push -u origin feature
```

---

### 3. Bob：CRITICAL 提交并推送

```bash
cd ../bob
git fetch
git switch feature
```

**文件** `workspaces-lost/bob/note.txt`：

```text
alice-1
bob-1 CRITICAL
```

```bash
git add .
git commit -m "feat: Bob CRITICAL fix B1 (already pushed)"
git push origin feature
git rev-parse --short HEAD
# 记下 bobShort
git rev-parse HEAD
# 记下 bobSha（完整）
```

---

### 4. Alice：不 fetch；推进 main；rebase 过期 feature

```bash
cd ../alice
git switch main
```

**文件** `workspaces-lost/alice/note.txt`：

```text
base
main-hotfix
```

```bash
git add .
git commit -m "fix(main): hotfix"
git push origin main

git switch feature
git log --oneline -3
# 仍只有 A1，看不到 CRITICAL

git rebase main
```

若冲突，覆盖 `note.txt`：

```text
base
main-hotfix
alice-1-rebased
```

```bash
git add note.txt
git -c core.editor=true rebase --continue
git log --oneline --graph --all --decorate -15
```

---

### 5. `--force-with-lease` 应拒绝

```bash
git push --force-with-lease origin feature
# 预期：rejected / stale info
```

---

### 6. 裸 `--force` 覆盖

```bash
git push --force origin feature
```

回到仓库根目录检查远程：

```bash
cd ../..
git --git-dir=workspaces-lost/origin.git log --oneline feature -5
git --git-dir=workspaces-lost/origin.git branch --contains <bobSha>
# 预期：空输出
```

---

## 完成后应有 / 验证

| 观察点 | 预期 |
| --- | --- |
| `--force-with-lease` | 拒绝 |
| `--force` | 成功；远程图上无 CRITICAL |
| `branch --contains <bobSha>` | 空 |
| Bob 本地 `git log` | 仍有 B1 |

自检：

```bash
git -C workspaces-lost/bob log --oneline -3
git --git-dir=workspaces-lost/origin.git log --oneline feature -5
```

Alice 再 `git pull` **找不回** B1。抢救示例：

```bash
cd workspaces-lost/bob
git fetch origin
git cherry-pick <bobShort>
# 协商后再 push（可能再冲突）
```
