# 01 — 场景A：实验准备

对应脚本：`[scripts/00-reset-workspace.py](../scripts/00-reset-workspace.py)`

作用：清空 `workspaces/`，再建裸远程，并克隆出 Alice / Bob 两个空工作区，方便后面手搓场景 A。

在仓库**根目录**操作。

---

## 方式一：一键（推荐）

关掉编辑器里 `workspaces/` 下已打开的标签（避免 Windows 文件锁），然后：

```bash
python scripts/00-reset-workspace.py
```

脚本内部依次做：

1. `reset_dir(workspaces)` — 清空并重建目录
2. `init_bare(origin.git)` — `git init --bare -b main`（默认分支 main，不是 master）
3. `init_clone` Alice / Bob — clone + 设置 `user.name` / `user.email`

---

## 建议先配的 Git 别名（本机一次即可）

后面场景里会反复看「图谱 + 全部分支」。社区常用 **`lg`**（log graph），好记，建议保留这个名字。

在任意目录执行（写入**全局**配置，对本机所有仓库生效）：

```bash
git config --global alias.lg "log --oneline --graph --all --decorate"
```

之后等价于：

```bash
git lg
# = git log --oneline --graph --all --decorate
```

本实验里同样高频、可选再加：

```bash
# 精简状态（看分支、脏文件）
git config --global alias.st "status -sb"

# 最近几条（不想看全图时）
git config --global alias.ll "log --oneline -15 --decorate"
```

| 别名 | 展开 | 何时用 |
| --- | --- | --- |
| `lg` | `log --oneline --graph --all --decorate` | 验证分叉、双胞胎、rebase 结果（首选） |
| `st` | `status -sb` | 看是否冲突 / 当前分支 |
| `ll` | `log --oneline -15 --decorate` | 只看最近几条、不要整图 |

自检别名是否生效：

```bash
git config --global --get alias.lg
git lg
# 空仓库可能几乎无输出；配完后进后面实验再看图谱即可
```

> 说明：`--global` 改的是你用户级 Git 配置，不是本演示仓库专属。若只想在某个仓库用，去掉 `--global`，在该仓库里执行即可。  
> 本助手不会替你改全局 `git config`；请自行粘贴执行。

## 方式二：手搓（与脚本等价）

### 1. 清空 workspaces

```bash
# Linux / macOS / Git Bash
rm -rf workspaces
mkdir workspaces

# Windows PowerShell（先关 workspaces 下标签）
# Remove-Item -Recurse -Force workspaces -ErrorAction SilentlyContinue
# New-Item -ItemType Directory -Force -Path workspaces | Out-Null
```

### 2. 初始化裸仓（默认分支 main）

```bash
git init --bare -b main workspaces/origin.git

# 确认 HEAD 指向 main
git --git-dir=workspaces/origin.git symbolic-ref HEAD
# 期望：refs/heads/main
```

### 3. 克隆 Alice / Bob 并设置作者

```bash
git clone workspaces/origin.git workspaces/alice
git -C workspaces/alice config user.name "Alice"
git -C workspaces/alice config user.email "alice@example.com"

git clone workspaces/origin.git workspaces/bob
git -C workspaces/bob config user.name "Bob"
git -C workspaces/bob config user.email "bob@example.com"
```

```bash
git -C workspaces/alice remote -v
git -C workspaces/alice config user.name
git -C workspaces/bob config user.name
```
