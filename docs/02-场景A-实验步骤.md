# 02 — 场景A：实验步骤（公共 rebase → 冲突）

对应脚本：[`scripts/01-scenario-A-duplicate-history.py`](../scripts/01-scenario-A-duplicate-history.py)

作用：复现 Alice 对公共 `feature` 做 `rebase` + 强推后，Bob 常规 `pull` 陷入冲突 / 分叉历史。

前置：已完成 [01-场景A-实验准备.md](./01-场景A-实验准备.md)。  

```bash
# 若没有手动逐步验证，可用脚本初始化
# 在根目录下执行
python scripts/00-reset-workspace.py

#执行后清空工作区，重置两个用户alice bob状态
```

1. 此时工作区状态干净， workspaces中，有裸仓库（模拟远端）、Alice 
2. 后续手操验证在仓库**根目录**操作。改文件时：打开对应路径，**整段覆盖粘贴**后保存。

## 方式二：手搓（与脚本等价）

### 1. 确认环境

```bash
ls workspaces
# 应有 origin.git / alice / bob
```

若没有，先跑 [01-场景A-实验准备](./01-场景A-实验准备.md)。

---

### 2. Alice：baseline → 推送 main

```bash
cd workspaces/alice
git switch -c main
```

**文件** `workspaces/alice/README.md`：

```markdown
# Team Chat

shared baseline
```

**文件** `workspaces/alice/app.py`：

```python
VERSION = '0.1'

def greet(name):
    return f'Hello, {name}'
```

```bash
git add .
git commit -m "init: shared baseline"
git push -u origin main
```

---

### 3. Alice：创建并推送 feature

```bash
git switch -c feature
git push -u origin feature
```

---

### 4. Alice：feature 上加 login 并推送

**文件** `workspaces/alice/README.md`：

```markdown
# Team Chat

- login
```

**文件** `workspaces/alice/app.py`：

```python
VERSION = '0.1'

def greet(name):
    return f'Hello, {name}'

def login(user, password):
    return user == 'admin' and password == 'secret'
```

```bash
git add .
git commit -m "feat(feature): add login (Alice)"
git push origin feature
```

---

### 5. Bob：拉 feature，加 send_message 并推送

```bash
cd ../bob
git fetch
git switch feature
git pull origin feature
```

**文件** `workspaces/bob/README.md`：

```markdown
# Team Chat

- login
- messages
```

**文件** `workspaces/bob/app.py`：

```python
VERSION = '0.1'

def greet(name):
    return f'Hello, {name}'

def login(user, password):
    return user == 'admin' and password == 'secret'

def send_message(user, text):
    return f'{user}: {text}'
```

```bash
git add .
git commit -m "feat(feature): add send_message (Bob)"
git push origin feature
```

---

### 6. Alice：同步并记下 oldTip

```bash
cd ../alice
git pull origin feature
git rev-parse --short HEAD
# 记下输出 → oldTip（后面 03/04 恢复要用）
git log --oneline --graph --all --decorate -10
```

### 8. Bob：旧 feature 上本地开发（先别 push）

```bash
cd ../bob
git switch feature
```

**文件** `workspaces/bob/README.md`：

```markdown
# Team Chat

- login
- messages
- emoji reactions (Bob WIP)
```

**文件** `workspaces/bob/app.py`：

```python
VERSION = '0.1'

def greet(name):
    return f'Hello, {name}'

    return user == 'admin' and password == 'secret'

```

```bash
git add .
git commit -m "feat(feature): add emoji reactions (Bob local)"
git rev-parse --short HEAD
# 记下 → bobOnly
```

---

### 9. Alice：rebase feature 到 origin/main，再强推

```bash
cd ../alice
git switch feature
git fetch origin
git rebase origin/main
```

若冲突（常见），按下面覆盖后 continue。

**冲突 1（login）** — `workspaces/alice/README.md`：

```markdown
# Team Chat

- security patch on main
- login
```

**冲突 1** — `workspaces/alice/app.py`：

```python
VERSION = '0.2'

def greet(name):
    return f'Hello, {name}!'

def login(user, password):
    return user == 'admin' and password == 'secret'
```

```bash
git add README.md app.py
git rebase --continue
# -c 表示 不弹编辑器，适合脚本 / 文档里一键继续
# git -c core.editor=true rebase --continue
```

**冲突 2（send_message，若再次冲突）** — `README.md`：

```markdown
# Team Chat

- security patch on main
- login
- messages
```

**冲突 2** — `app.py`：

```python
VERSION = '0.2'

def greet(name):
    return f'Hello, {name}!'

def login(user, password):
    return user == 'admin' and password == 'secret'

def send_message(user, text):
    return f'{user}: {text}'
```

```bash
git add README.md app.py
git -c core.editor=true rebase --continue
git log --oneline --graph --all --decorate -15
git push --force-with-lease origin feature
```

---

### 10. Bob：常规 pull（制造冲突）

```bash
cd ../bob
git fetch origin
git pull origin feature --no-edit
```

## 完成后应有 / 验证

| 观察点 | 预期 |
| --- | --- |
| `git -C workspaces/bob status` | 合并冲突进行中（UU） |
| `git log --graph --all`（在 bob） | 旧 SHA 与 rebase 后新 SHA 分叉并存 |
| `README.md` / `app.py` | 含冲突标记 |
| 记下的 `oldTip` / `bobOnly` | 非空短哈希 |

自检：

```bash
cd workspaces/bob
git status
git log --oneline --graph --all --decorate -20
# Linux/macOS:
cat README.md
# Windows: type README.md
```

可选写入元数据（供后续恢复脚本）：

```bash
cd ../..
# 把哈希换成你记下的值
printf '{\n  "oldTip": "这里填oldTip",\n  "bobOnly": "这里填bobOnly"\n}\n' > workspaces/scenario-A-meta.json
```
